# iReachFlow

iReachFlow — reach your target contact list with customized messages.

## Structure

- [`backend/`](backend/) — NestJS API (email delivery, target lists, reporting)
- [`frontend/`](frontend/) — Angular app (mail preparation, target base, reports)

## Brand assets

The logo lives in [`frontend/src/assets/branding/`](frontend/src/assets/branding/) (`ireachflow-logo.svg` / `.png`) and is used as the app favicon and toolbar mark.
